# 共享内存增强设计

## 一、当前问题分析

### 1.1 SharedMemory 现状

当前的 SharedMemory 只是一个简单的键值存储：

```typescript
export class SharedMemory {
  private namespaces: Map<string, Map<string, MemoryEntry>> = new Map();

  set(namespace: string, key: string, value: unknown, agentId: string): void { ... }
  get(namespace: string, key: string): unknown | undefined { ... }
  keys(namespace: string): string[] { ... }
  has(namespace: string, key: string): boolean { ... }
  delete(namespace: string, key: string): boolean { ... }
  clear(namespace: string): void { ... }
}
```

### 1.2 存在的问题

| 问题 | 影响 |
|------|------|
| 没有持久化 | 内存中的数据会丢失，无法跨会话 |
| 没有同步机制 | 多个 worker 无法协调访问 |
| 没有上下文注入 | 无法自动填充任务相关信息 |
| 没有历史追踪 | 无法知道之前执行了什么 |
| 没有类型安全 | 值是 `unknown`，需要手动转换 |

## 二、增强设计方案

### 2.1 核心设计原则

1. **渐进增强** - 保持向后兼容，逐步添加新功能
2. **职责分离** - 存储、同步、持久化分开
3. **类型安全** - 使用泛型提供类型提示
4. **自动填充** - 上下文构建器自动填充常用数据

### 2.2 增强的 SharedMemory 接口

```typescript
/**
 * 增强的共享内存接口
 */
export interface EnhancedSharedMemory extends SharedMemory {
  // ── 持久化 ──────────────────────────────────────────────────
  /**
   * 保存到文件
   */
  save(filepath: string): Promise<void>;
  
  /**
   * 从文件加载
   */
  load(filepath: string): Promise<void>;
  
  // ── 批量操作 ────────────────────────────────────────────────
  /**
   * 批量设置
   */
  setMany(namespace: string, entries: Record<string, unknown>, agentId: string): void;
  
  /**
   * 批量获取
   */
  getMany(namespace: string, keys: string[]): Record<string, unknown>;
  
  // ── 查询 ────────────────────────────────────────────────────
  /**
   * 按前缀查询
   */
  getByPrefix(namespace: string, prefix: string): Record<string, unknown>;
  
  /**
   * 获取所有命名空间
   */
  namespaces(): string[];
  
  // ── 历史追踪 ────────────────────────────────────────────────
  /**
   * 获取键的修改历史
   */
  history(namespace: string, key: string): MemoryHistoryEntry[];
  
  // ── 快照 ────────────────────────────────────────────────────
  /**
   * 创建快照
   */
  snapshot(): MemorySnapshot;
  
  /**
   * 从快照恢复
   */
  restore(snapshot: MemorySnapshot): void;
}
```

### 2.3 上下文构建器设计

```typescript
/**
 * 执行上下文接口
 */
export interface ExecutionContext {
  // ── 基础信息 ────────────────────────────────────────────────
  role: string;
  task: string;
  style: string;
  cwd: string;
  
  // ── 共享内存 ────────────────────────────────────────────────
  memory: EnhancedSharedMemory;
  
  // ── 信号总线 ────────────────────────────────────────────────
  bus: SignalBus;
  
  // ── 任务上下文 ──────────────────────────────────────────────
  taskContext: TaskContext;
  
  // ── 项目上下文 ──────────────────────────────────────────────
  projectContext: ProjectContext;
  
  // ── 执行历史 ────────────────────────────────────────────────
  executionHistory: ExecutionHistory;
}

/**
 * 任务上下文
 */
export interface TaskContext {
  id: string;
  name: string;
  type: string;
  status: string;
  goal: string;
  scope: {
    include: string[];
    exclude: string[];
  };
  acceptance: string[];
  sections: Record<string, string>;
}

/**
 * 项目上下文
 */
export interface ProjectContext {
  root: string;
  structure: DirectoryStructure;
  relatedFiles: RelatedFile[];
  dependencies: string[];
  config: ProjectConfig;
}

/**
 * 执行历史
 */
export interface ExecutionHistory {
  previousResults: ExecutionResult[];
  decisions: Decision[];
  learnings: string[];
}

/**
 * 上下文构建器
 */
export class ContextBuilder {
  constructor(
    private cwd: string,
    private memory: EnhancedSharedMemory,
    private bus: SignalBus,
  ) {}
  
  /**
   * 构建完整的执行上下文
   */
  async build(config: WorkerConfig): Promise<ExecutionContext> {
    // 1. 并行获取各种上下文
    const [taskContext, projectContext, executionHistory] = await Promise.all([
      this.buildTaskContext(config.task),
      this.buildProjectContext(),
      this.buildExecutionHistory(),
    ]);
    
    // 2. 存储到共享内存
    this.memory.setMany('task', {
      details: taskContext,
      config: config,
    }, 'context-builder');
    
    this.memory.setMany('project', {
      structure: projectContext.structure,
      relatedFiles: projectContext.relatedFiles,
    }, 'context-builder');
    
    this.memory.setMany('execution', {
      history: executionHistory,
    }, 'context-builder');
    
    // 3. 返回完整上下文
    return {
      role: getRequiredOption(config.options, 'role'),
      task: config.task,
      style: config.style,
      cwd: this.cwd,
      memory: this.memory,
      bus: this.bus,
      taskContext,
      projectContext,
      executionHistory,
    };
  }
  
  /**
   * 构建任务上下文
   */
  private async buildTaskContext(taskDescription: string): Promise<TaskContext> {
    // 从 task 工具获取任务详情
    // 搜索相关任务
    // 解析任务目标和范围
    return {
      id: '',
      name: '',
      type: '',
      status: '',
      goal: taskDescription,
      scope: { include: [], exclude: [] },
      acceptance: [],
      sections: {},
    };
  }
  
  /**
   * 构建项目上下文
   */
  private async buildProjectContext(): Promise<ProjectContext> {
    // 读取目录结构
    // 搜索相关文件
    // 读取配置文件
    return {
      root: this.cwd,
      structure: await this.getDirectoryStructure(),
      relatedFiles: [],
      dependencies: [],
      config: {},
    };
  }
  
  /**
   * 构建执行历史
   */
  private async buildExecutionHistory(): Promise<ExecutionHistory> {
    // 从共享内存获取历史
    const history = this.memory.get('execution', 'history') as ExecutionHistory | undefined;
    return history || {
      previousResults: [],
      decisions: [],
      learnings: [],
    };
  }
}
```

## 四、使用示例

### 4.1 创建 Worker 并执行

```typescript
// 1. 创建上下文构建器
const contextBuilder = new ContextBuilder(cwd, memory, bus);

// 2. 构建执行上下文
const context = await contextBuilder.build({
  type: 'solo',
  task: '实现用户登录功能',
  style: 'explore',
  options: [{ type: 'role', value: 'build' }],
});

// 3. 创建执行器
const executor = createExecutor(context);

// 4. 执行任务
const result = await executor(context);
```

### 4.2 在执行器中使用上下文

```typescript
function createExecutor(context: ExecutionContext): Executor {
  return async (ctx) => {
    // 1. 从上下文获取任务详情
    const { taskContext, projectContext } = ctx;
    
    // 2. 从共享内存获取历史
    const history = ctx.memory.get('execution', 'history');
    
    // 3. 执行任务
    const result = await executeTask(ctx);
    
    // 4. 更新共享内存
    ctx.memory.set('execution', 'results', result, ctx.role);
    
    // 5. 发送信号
    ctx.bus.emit('progress', ctx.role, { status: 'done', result });
    
    return result;
  };
}
```

## 五、优势

1. **上下文完整** - 执行器可以获取任务、项目、历史等完整上下文
2. **数据共享** - 多个 worker 可以通过共享内存协作
3. **可追溯** - 所有操作都有历史记录
4. **可恢复** - 支持快照和恢复
5. **类型安全** - 使用泛型提供类型提示

## 六、风险与缓解

| 风险 | 缓解措施 |
|------|----------|
| 性能问题 | 使用懒加载、缓存、增量更新 |
| 内存溢出 | 设置内存上限、定期清理 |
| 数据一致性 | 使用锁机制、版本控制 |
| 复杂度增加 | 渐进增强、保持简单 |
