# 工具接口

> **定位**：dteam 的基础层。定义 task 的工具接口。依赖 task（P0）。

## 一句话

工具接口是 dteam 的**操作入口**——通过工具操作 task。

## 工具列表

| 工具 | 功能 | 参数 |
|------|------|------|
| `task.create` | 创建新任务 | `{ name, type, why, goal }` |
| `task.read` | 读取指定section | `{ id, section }` |
| `task.update` | 更新指定section | `{ id, section, content }` |
| `task.complete` | 标记checklist项为完成 | `{ id, item }` |
| `task.archive` | 归档完成的任务 | `{ id }` |

## 工具详细说明

### task.create

创建新的 task。

**参数**：
```typescript
interface TaskCreateInput {
  name: string;           // 任务名称
  type: TaskType;         // 任务类型：functional/ui/bugfix/refactor/infra
  why: string;            // 为什么要做
  goal: string;           // 目标是什么
}
```

**返回**：
```typescript
interface TaskCreateOutput {
  id: string;             // 任务ID
  filename: string;       // 文件名
  path: string;           // 文件路径
}
```

**示例**：
```json
{
  "name": "实现用户认证",
  "type": "functional",
  "why": "当前系统无任何身份验证机制",
  "goal": "实现基于JWT的用户注册、登录和token刷新流程"
}
```

### task.read

读取 task 的指定 section。

**参数**：
```typescript
interface TaskReadInput {
  id: string;             // 任务ID
  section: string;        // section名称：基本信息/目标/范围/验收条件/阶段记录
}
```

**返回**：
```typescript
interface TaskReadOutput {
  content: string;        // section内容
}
```

**示例**：
```json
{
  "id": "20260529141206-ofi4",
  "section": "验收条件"
}
```

### task.update

更新 task 的指定 section。

**参数**：
```typescript
interface TaskUpdateInput {
  id: string;             // 任务ID
  section: string;        // section名称
  content: string;        // 新内容
}
```

**返回**：
```typescript
interface TaskUpdateOutput {
  updated_at: string;     // 更新时间
}
```

**示例**：
```json
{
  "id": "20260529141206-ofi4",
  "section": "执行记录",
  "content": "### 2026-05-29 14:30\n- 完成用户注册API实现"
}
```

### task.complete

标记 checklist 项为完成。

**参数**：
```typescript
interface TaskCompleteInput {
  id: string;             // 任务ID
  item: string;           // checklist项内容
}
```

**返回**：
```typescript
interface TaskCompleteOutput {
  completed_at: string;   // 完成时间
}
```

**示例**：
```json
{
  "id": "20260529141206-ofi4",
  "item": "Given 未注册用户 When 通过POST /api/register注册 Then 返回201和有效token"
}
```

### task.archive

归档完成的任务。

**参数**：
```typescript
interface TaskArchiveInput {
  id: string;             // 任务ID
}
```

**返回**：
```typescript
interface TaskArchiveOutput {
  archived_at: string;    // 归档时间
  archive_path: string;   // 归档路径
}
```

**示例**：
```json
{
  "id": "20260529141206-ofi4"
}
```

## 工具使用流程

```
用户需求
    │
    ▼
task.create（创建任务）
    │
    ▼
explore/design/build/check/close（执行角色）
    │
    ▼
task.read/update/complete（操作任务）
    │
    ▼
task.archive（归档任务）
```
