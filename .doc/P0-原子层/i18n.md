# i18n 定义

> **定位**：dteam 的原子层。定义 i18n 基础能力。

## 一句话

i18n 是 dteam 的**国际化基础**——支持多语言输出。

## 支持的语言

| 语言 | 代码 | 说明 |
|------|------|------|
| 简体中文 | zh-Hans | 默认语言 |
| 繁体中文 | zh-Hant | 港澳台 |
| 日语 | ja | 日本 |
| 韩语 | ko | 韩国 |
| 德语 | de | 德国 |
| 法语 | fr | 法国 |
| 西班牙语 | es | 西班牙 |
| 葡萄牙语 | pt | 葡萄牙 |
| 俄语 | ru | 俄罗斯 |
| 阿拉伯语 | ar | 阿拉伯 |
| 英语 | en | 英国/美国 |

## 核心功能

| 功能 | 说明 |
|------|------|
| `detectLocale` | 从环境变量检测 locale |
| `languageForLocale` | 将 locale 映射到支持的语言 |
| `languageInstructionForLocale` | 为 LLM 生成语言指令 |

## 接口定义

```typescript
type SupportedLanguage = "zh-Hans" | "zh-Hant" | "ja" | "ko" | "de" | "fr" | "es" | "pt" | "ru" | "ar" | "en";

// 从环境变量检测 locale
function detectLocale(env?: NodeJS.ProcessEnv): string | undefined;

// 将 locale 映射到支持的语言
function languageForLocale(locale?: string): SupportedLanguage;

// 为 LLM 生成语言指令
function languageInstructionForLocale(locale?: string): string;
```

## 环境变量

| 变量 | 优先级 | 说明 |
|------|--------|------|
| PI_LOCALE | 1 | Pi 设置的 locale |
| LC_ALL | 2 | 系统 locale |
| LANG | 3 | 系统语言 |

- 代码：`src/P0/i18n.ts`
- 测试：`tests/unit/i18n.test.ts`
