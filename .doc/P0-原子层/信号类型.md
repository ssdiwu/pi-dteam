# 信号类型定义

> **定位**：dteam 的原子层。定义信号和策略类型，用于 worker 之间的即时通信。

## 一句话

信号是 worker 之间的**即时通信机制**——4 个信号 + 5 个策略 = 9 种信号类型。

## 信号分类

| 类别 | 信号 | 说明 |
|------|------|------|
| 状态报告 | `progress` | 报告当前进度 |
| 状态报告 | `blocked` | 遇到阻塞 |
| 状态报告 | `found` | 发现信息 |
| 协调请求 | `help` | 请求外部帮助 |

## 策略分类

| 类别 | 策略 | 说明 |
|------|------|------|
| 恢复策略 | `retry` | 重试当前操作 |
| 恢复策略 | `adjust` | 调整参数后重试 |
| 恢复策略 | `switch` | 切换到其他工具/方法 |
| 规划策略 | `replan` | 重新规划任务 |
| 学习策略 | `learn` | 记录经验教训 |

## 信号定义

```typescript
interface Signal {
  id: string;           // signal-{timestamp}-{random4}
  type: SignalType;     // 信号类型
  workerId: string;     // 发送者ID
  timestamp: number;    // 时间戳
  data: Record<string, unknown>;  // 附加数据
}

type SignalType = "progress" | "blocked" | "found" | "help";
type StrategyType = "retry" | "adjust" | "switch" | "replan" | "learn";
```

## 使用示例

```typescript
// 发送进度信号
bus.emit("progress", "worker-0", { percent: 50 });

// 发送阻塞信号
bus.emit("blocked", "worker-1", { reason: "缺少依赖" });

// 监听信号
bus.on("blocked", (signal) => {
  console.log(`Worker ${signal.workerId} 被阻塞: ${signal.data.reason}`);
});
```

## 信号流转

```
worker 执行任务
    │
    ├─ 正常 → progress 信号
    │
    ├─ 遇到问题 → blocked 信号
    │   │
    │   └─ 主 worker 下发策略
    │       ├─ retry → 重试
    │       ├─ adjust → 调整参数
    │       ├─ switch → 切换方法
    │       ├─ replan → 重新规划
    │       └─ learn → 记录经验
    │
    ├─ 发现信息 → found 信号
    │
    └─ 需要帮助 → help 信号
```
