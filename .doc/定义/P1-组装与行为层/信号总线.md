# 信号总线

> **定位**：dteam 的通信基础设施。worker 之间、worker 与外部通过信号总线进行即时通信。

## 一句话

信号总线是 dteam 的**神经系统**——实现 worker 之间的即时通信。

## 核心特征

| 特征 | 值 |
|------|-----|
| 通信方式 | 进程内即时通信 |
| 信号类型 | 13种（详见信号类型.md） |
| 生命周期 | 与 team 实例绑定 |

## 架构设计

```
┌─────────────────────────────────────────────────────────┐
│                      信号总线                            │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   ┌──────────┐    ┌──────────┐    ┌──────────┐          │
│   │ worker1  │───▶│          │◀───│ worker3  │          │
│   └──────────┘    │  Signal  │    └──────────┘          │
│                   │   Bus    │                          │
│   ┌──────────┐    │          │    ┌──────────┐          │
│   │ worker2  │───▶│          │◀───│ 外部事件  │          │
│   └──────────┘    └──────────┘    └──────────┘          │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 信号流向

```
外部事件 → 信号 → Worker
Worker → 信号 → 其他 Worker
Worker → 信号 → 用户（上报）
```

## 信号处理

| 场景 | 处理方式 |
|------|---------|
| 阻塞信号 | worker 暂停，等待外部解除 |
| 进度信号 | 记录日志，不阻塞 |
| 错误信号 | 触发策略恢复 |
| 上报信号 | 转发给用户决策 |

## 接口定义

### 发送信号

```typescript
interface SignalBus {
  emit(signal: Signal): void;
  on(signalType: SignalType, handler: (signal: Signal) => void): void;
  query(signalType: SignalType): Signal[];
}
```

### 信号结构

```typescript
interface Signal {
  type: SignalType;
  workerId: string;
  payload: Record<string, unknown>;
  timestamp: number;
}
```

## 使用场景

### 1. 进度报告

```typescript
// worker 报告进度
signalBus.emit({
  type: "progress",
  workerId: "worker-1",
  payload: { output: "已完成 50%" },
  timestamp: Date.now()
});
```

### 2. 阻塞报告

```typescript
// worker 报告阻塞
signalBus.emit({
  type: "blocked",
  workerId: "worker-1",
  payload: { reason: "依赖未安装" },
  timestamp: Date.now()
});
```

### 3. 求助请求

```typescript
// worker 请求帮助
signalBus.emit({
  type: "help",
  workerId: "worker-1",
  payload: { question: "如何处理这个错误？" },
  timestamp: Date.now()
});
```

## 不变量

1. 信号不可变——一旦发出，不可修改或撤回
2. TTL 过期——默认 5 分钟后信号从 query 结果中消失
3. 进程内通信——信号总线不走网络
4. 生命周期与 team 实例绑定
