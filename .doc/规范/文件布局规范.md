## 文件命名规则

### task 文件

格式：`{name}-{timestamp}-{random4}.md`

- `name`：任务名称（简短描述）
- `timestamp`：`YYYYMMDDHHmmss` 格式
- `random4`：4 位随机字符（防碰撞）
- 示例：`实现用户认证-20260529141206-ofi4.md`

### 文档文件

格式：`{名称}.md`

- 使用中文名称
- 保持简洁
- 示例：`task.md`、`角色.md`

### 目录名

- 使用中文或英文
- 保持一致
- 示例：`定义`、`P0-数据模型层`

## 版本控制

### .gitignore

```
# dteam 数据目录（可选忽略）
.dteam/task/
.dteam/archive/

# 文档目录（需要版本控制）
.doc/
```

### 建议

- `.doc/` 目录需要版本控制
- `.dteam/` 目录可选忽略（取决于团队需求）
- task 文件可选忽略（如果使用归档机制）
