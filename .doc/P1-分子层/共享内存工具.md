# 共享内存工具

> **定位**：dteam 的分子层。定义共享内存工具接口。

## 一句话

共享内存工具是 dteam 的**数据共享接口**——提供共享内存的读写能力。

## 工具清单

| 工具 | 功能 | 参数 |
|------|------|------|
| `memory_get` | 从共享内存获取值 | `{ namespace, key }` |
| `memory_set` | 向共享内存设置值 | `{ namespace, key, value, agentId }` |
| `memory_keys` | 列出命名空间下的所有键 | `{ namespace }` |
| `memory_has` | 检查键是否存在 | `{ namespace, key }` |
| `memory_delete` | 删除键 | `{ namespace, key }` |
| `memory_clear` | 清空命名空间 | `{ namespace }` |
| `memory_save` | 保存共享内存到文件 | `{ filepath }`（相对 `.dteam/memory/`，仅允许 `.json`） |
| `memory_load` | 从文件加载共享内存 | `{ filepath }`（相对 `.dteam/memory/`，仅允许 `.json`） |

## 使用示例

```typescript
// 设置值
await memorySet(ctx, {
  namespace: "task-1",
  key: "result",
  value: { success: true },
  agentId: "worker-0",
});

// 获取值
const result = await memoryGet(ctx, {
  namespace: "task-1",
  key: "result",
});

// 列出所有键
const keys = await memoryKeys(ctx, {
  namespace: "task-1",
});

// 检查键是否存在
const exists = await memoryHas(ctx, {
  namespace: "task-1",
  key: "result",
});

// 删除键
await memoryDelete(ctx, {
  namespace: "task-1",
  key: "result",
});

// 清空命名空间
await memoryClear(ctx, {
  namespace: "task-1",
});

// 保存到文件（实际落盘到 .dteam/memory/session.json）
await memorySave(ctx, {
  filepath: "session.json",
});

// 从文件加载
await memoryLoad(ctx, {
  filepath: "session.json",
});
```
