# 信号总线

> **定位**：dteam 的分子层。定义信号总线，用于 worker 之间的即时通信。依赖信号（P0）。

## 一句话

信号总线是 worker 之间的**通信中枢**——发送、监听、记录信号。

## 核心功能

| 功能 | 说明 |
|------|------|
| `emit` | 发送信号 |
| `on` | 监听信号 |
| `getHistory` | 获取信号历史 |

## 接口定义

```typescript
class SignalBus {
  // 发送信号
  emit(type: SignalType, workerId: string, data?: Record<string, unknown>): Signal;
  
  // 监听信号，返回取消监听函数
  on(type: SignalType, listener: (signal: Signal) => void): () => void;
  
  // 获取信号历史
  getHistory(workerId?: string): Signal[];
}
```

## 使用示例

```typescript
const bus = new SignalBus();

// 发送进度信号
bus.emit("progress", "worker-0", { percent: 50 });

// 监听信号
const unsub = bus.on("progress", (signal) => {
  console.log(`Worker ${signal.workerId} 进度: ${signal.data.percent}%`);
});

// 获取信号历史
const history = bus.getHistory("worker-0");

// 取消监听
unsub();
```
