# 共享内存

> **定位**：dteam 的分子层。定义共享内存，用于 worker 之间共享数据。依赖内存条目（P0）。

## 一句话

共享内存是 worker 之间的**数据共享中枢**——按命名空间存储键值对。

## 核心功能

| 功能 | 说明 |
|------|------|
| `set` | 设置值 |
| `get` | 获取值 |
| `has` | 检查键是否存在 |
| `delete` | 删除键 |
| `keys` | 列出命名空间下的所有键 |
| `clear` | 清空命名空间 |

## 接口定义

```typescript
class SharedMemory {
  // 设置值
  set(namespace: string, key: string, value: unknown, agentId: string): void;
  
  // 获取值
  get(namespace: string, key: string): unknown | undefined;
  
  // 检查键是否存在
  has(namespace: string, key: string): boolean;
  
  // 删除键
  delete(namespace: string, key: string): boolean;
  
  // 列出命名空间下的所有键
  keys(namespace: string): string[];
  
  // 清空命名空间
  clear(namespace: string): void;
}
```

## 使用示例

```typescript
const memory = new SharedMemory();

// 设置值
memory.set("task-1", "result", { success: true }, "worker-0");

// 获取值
const result = memory.get("task-1", "result");

// 检查键是否存在
if (memory.has("task-1", "result")) {
  console.log("结果已存在");
}

// 列出所有键
const keys = memory.keys("task-1");

// 删除键
memory.delete("task-1", "result");

// 清空命名空间
memory.clear("task-1");
```

## 命名空间

- 按任务划分命名空间
- 每个 worker 只能访问自己的命名空间
- 主 worker 可以访问所有命名空间
