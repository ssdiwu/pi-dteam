# 信号工具

> **定位**：dteam 的分子层。定义信号工具接口。

## 一句话

信号工具是 dteam 的**即时通信接口**——提供信号的发送和监听能力。

## 工具清单

| 工具 | 功能 | 参数 |
|------|------|------|
| `signal_emit` | 发送信号 | `{ type, workerId, data? }` |
| `signal_history` | 获取信号历史 | `{ workerId? }` |

## 使用示例

```typescript
// 发送进度信号
await signalEmit(ctx, {
  type: "progress",
  workerId: "worker-0",
  data: { percent: 50 },
});

// 发送阻塞信号
await signalEmit(ctx, {
  type: "blocked",
  workerId: "worker-1",
  data: { error: "缺少依赖" },
});

// 发送help信号
await signalEmit(ctx, {
  type: "help",
  workerId: "worker-2",
  data: { question: "如何处理这个错误？" },
});

// 获取信号历史
const history = await signalHistory(ctx, {
  workerId: "worker-0",
});
```

## 信号类型

| 类型 | 说明 |
|------|------|
| `progress` | 报告进度 |
| `blocked` | 遇到阻塞 |
| `found` | 发现信息 |
| `help` | 请求帮助 |
