# 工具接口

> **定位**：dteam 的基础层。定义所有工具接口。

## 一句话

工具是 dteam 的**操作入口**——通过工具操作 task、reference、worker。

## 工具清单

### task 工具（7个）

| 工具 | 功能 | 参数 |
|------|------|------|
| `task_create` | 创建新的task | `{ name, type, why, goal }` |
| `task_read` | 读取task的指定section | `{ id, section }` |
| `task_update` | 更新task的指定section | `{ id, section, content }` |
| `task_complete` | 标记checklist项为完成 | `{ id, item }` |
| `task_archive` | 归档完成的任务 | `{ id }` |
| `task_list` | 列出所有task | `{ status? }` |
| `task_search` | 搜索task | `{ query }` |

### reference 工具（1个）

| 工具 | 功能 | 参数 |
|------|------|------|
| `reference_architecture` | 查询架构类型参考 | `{ query }` |

### worker 工具（3个）

| 工具 | 功能 | 参数 |
|------|------|------|
| `worker_create` | 创建worker实例 | `{ config }` |
| `worker_start` | 启动worker执行 | `{ workerId }` |
| `worker_sendSignal` | 发送信号到worker | `{ workerId, signalType, data? }` |

## 工具详情

### task_create

创建新的 task。

**参数**：
- `name`：任务名称
- `type`：任务类型（functional/ui/bugfix/refactor/infra）
- `why`：为什么要做
- `goal`：目标是什么

**返回**：
- `id`：任务ID
- `filename`：文件名
- `path`：文件路径

### task_read

读取 task 的指定 section。

**参数**：
- `id`：任务ID
- `section`：section名称（基本信息/目标/范围/验收条件/阶段记录）

**返回**：
- `id`：任务ID
- `section`：section名称
- `content`：section内容

### task_update

更新 task 的指定 section。

**参数**：
- `id`：任务ID
- `section`：section名称
- `content`：新内容

**返回**：
- `id`：任务ID
- `section`：section名称
- `message`：更新成功消息

### task_complete

标记 checklist 项为完成。

**参数**：
- `id`：任务ID
- `item`：checklist项内容

**返回**：
- `id`：任务ID
- `item`：checklist项内容
- `message`：完成消息

### task_archive

归档完成的任务。

**参数**：
- `id`：任务ID

**返回**：
- `id`：任务ID
- `sourcePath`：源文件路径
- `destPath`：目标文件路径
- `message`：归档消息

### task_list

列出所有 task。

**参数**：
- `status`：按状态过滤（可选）

**返回**：
- `tasks`：任务列表
- `count`：任务数量
- `message`：查询消息

### task_search

搜索 task。

**参数**：
- `query`：搜索关键词

**返回**：
- `tasks`：任务列表
- `count`：任务数量
- `message`：搜索消息

### reference_architecture

查询架构类型参考。

**参数**：
- `query`：查询关键词

**返回**：
- `query`：查询关键词
- `results`：查询结果
- `message`：查询消息

### worker_create

创建 worker 实例。

**参数**：
- `config`：WorkerConfig 配置

**返回**：
- `workerId`：Worker ID
- `config`：配置信息
- `message`：创建消息

### worker_start

启动 worker 执行。

**参数**：
- `workerId`：Worker ID

**返回**：
- `workerId`：Worker ID
- `result`：执行结果
- `message`：执行消息

### worker_sendSignal

发送信号到 worker。

**参数**：
- `workerId`：Worker ID
- `signalType`：信号类型
- `data`：信号数据（可选）

**返回**：
- `workerId`：Worker ID
- `signal`：信号信息
- `message`：发送消息
