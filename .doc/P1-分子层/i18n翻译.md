# i18n 翻译

> **定位**：dteam 的分子层。定义翻译表和翻译函数。依赖 i18n 基础（P0）。

## 一句话

i18n 翻译是 dteam 的**翻译中枢**——提供多语言翻译能力。

## 翻译范围

| 类别 | 键 | 说明 |
|------|-----|------|
| 通用 | dteam.name | 名称 |
| 通用 | dteam.active | 激活状态 |
| 状态 | status.pending | 准备中 |
| 状态 | status.running | 运行中 |
| 状态 | status.done | 完成 |
| 状态 | status.failed | 失败 |
| 任务 | task.todo | 待办 |
| 任务 | task.InSpec | 规格中 |
| 任务 | task.InProgress | 执行中 |
| 任务 | task.Done | 完成 |
| 任务 | task.Cancelled | 已取消 |
| 角色 | role.explore | 探索者 |
| 角色 | role.design | 方案制定者 |
| 角色 | role.build | 实现者 |
| 角色 | role.check | 验收者 |
| 角色 | role.close | 收口者 |
| 模式 | mode.solo | 单任务 |
| 模式 | mode.chain | 串行 |
| 模式 | mode.team | 并行 |

## 接口定义

```typescript
// 翻译函数
function t(key: string, locale?: string): string;
```

## 使用示例

```typescript
import { t } from "../P1/i18n.js";

// 自动检测 locale
console.log(t("status.pending")); // "准备中"

// 指定 locale
console.log(t("status.pending", "en-US")); // "Pending"
console.log(t("status.pending", "ja-JP")); // "準備中"
```

## Fallback 机制

1. 先查找目标语言的翻译
2. 如果没有，fallback 到 zh-Hans
3. 如果还没有，返回 key 本身
