# tui/

`/dteam` 的按需管理视图。只消费 Worker Snapshot，不拥有 worker 生命周期；运行中记录可查看，终态记录只读。浮窗顶端始终展示“运行中 / 历史记录 / 模型配置”三个标签，`▶` 标出当前内容；左右方向键或 `h/l` 循环切换，`m` 可直接进入模型配置。列表默认运行中，历史按终态时间倒序显示。详情以 worker ID 保持目标，即使 worker 在查看时终态化也会封存显示；无 `ui.custom()` 时降级为同时输出两个 worker 视图。列表和详情使用有界视口，支持方向键、`j/k`、`PgUp/PgDn`、`Home/End` 浏览，避免 worker 堆积被 Modal 裁切。详情展示有界实时文本、thinking、当前工具、最后活动、timeout 诊断、当前 worker 的局部 `writeScope`（不代表父任务完成），以及终态报告的 outcome、activities、verification、facts、remaining 和 uncertainties；刷新由运行时节流。公开工具的 `Ctrl+O` 展开也使用同一人类可读语义，不暴露原始 JSON。`model-config-dialog.ts` 支持编辑 T1/T2/T3 的完整候选链、候选排序和每候选 thinking；模型目录只读取 Pi 当前认证可用的模型，保存只更新后续 dispatch，已受理 worker 保留派发时的路由快照。`dteam-dialog.ts` 使用有包边的 Modal 和 `i18n.ts` 的 `pi.i18n.v1` bundle；默认中文，接入 `pi-di18n` 后按 locale 切换。
