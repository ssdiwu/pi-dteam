## 目标
- 为什么: dteam 当前 worker widget 是个 bordered box 显示基础信息（参考 src/P4/worker-widget.ts），用户看不到 worker 实时输出、工具调用、token 消耗。subagents 的 Ctrl+O 展开全屏流让用户能看到完整 streaming 输出。dteam 缺这个，复杂任务调试只能靠日志。
- 做什么: 为 dteam worker widget 补 Ctrl+O 展开全屏进度流：折叠态=现有 widget；展开态=全屏流显示当前 tool / recent output / token count / duration / activity freshness / current-tool duration。模仿 subagents 的展开 UX 但用 dteam 自己的 AgentProgress 数据源。
