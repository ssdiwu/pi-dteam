## 目标
- 为什么: dteam 当前并行 worker 改同一 git 仓库会冲突（src/P2/team.ts:33 用 mapWithConcurrencyLimit 并行运行多个 worker，没有文件级隔离）。subagents 用 git worktree 解决，any 用文件锁，dteam 现在两样都没有。并行 build/check 阶段高概率踩坑。
- 做什么: 为 dteam 并行 worker 引入 git worktree 隔离：worker_start 时如果 worker 配置声明 worktree: true 且 cwd 是 git 仓库，自动创建 worktree 分支、worker 在 worktree 中运行、worker 完成后可选自动 merge 或保留分支给用户决策。
