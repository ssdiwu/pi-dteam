## 当前文档原则

1. **定位先行**：dteam 不是通用工作流平台，也不是固定工业流水线；它是 Pi 里的轻量多 worker 协作状态。
2. **后台运行**：`dteam(action="run")` 立即返回 `runId`，进度走 `/dteam` 面板 / widget（小组件）/ 状态栏，完成后发 `dteam-report`（结果报告）。
3. **角色写死是有意设计**：当前 5 个角色足够，暂不借鉴 pi-subagents 的前端可配置角色体系。
4. **外部参考只借轻动作**：借 UI、可观测、状态边界、自然语言可用性；不照搬固定流水线、重型持久化、进程树或完整多 agent 平台。
5. **路线图三档**：要做 / 暂不做 / 远期，不用“抛弃”表达有价值但暂时不做的方向。
