## 1. v1 业务能力（全部完成）

### 4 种信号通路
- `progress` / `found` / `blocked` / `help` 信号类型
- 内存 `SignalBus` + `RunsStore`
- 叶子通过 `worker_sendSignal` 工具上报

### help 自愈 + 升级人类
- 首次 help → 根派 explore 收集 → resolve 叶子 pendingSupplements
- 第 2 次 help → 升级到人类 → ctx.ui.notify → 等 `dteam(action="continue", runId, message)`

### 后台运行
- `dteam(action="run", goal)` 立即返回 runId（不阻塞前台）
- 后台异步执行，run 完成后自动 `pi.sendMessage` 注入主对话（triggerTurn + followUp）

### 链式继承 + 实时转发
- 链式：派下一个 step 前把前序 found/progress 摘要拼到 prompt
- 实时：根监听 found/progress → 写入 injectionQueue → 正在跑的叶子 await 时取出

### reference_architecture 工具
- 12 个架构模式 + ADR 草稿模板
- 仅 design 角色可用
