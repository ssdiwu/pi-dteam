# 结构化工作报告与有界上下文交接

> **状态：已定，待下一主版本实施**
>
> **补充**：补充 ADR 0013 的三工具公开契约与 ADR 0014 的 T3 → T2 → T1 递增成本纪律；保留 ADR 0009 的星型 signal 协议与 Logical Isolation（逻辑隔离）。

下一主版本中，每个 T1/T2/T3 worker 都必须在结束前通过内部 `dteam_report` 工具提交结构化工作报告，至少包含 `summary` 和带 `claim` / `evidence` 的 `facts`，可附 `uncertainties`。Worker Manager 只将有效报告的 worker 视为 `completed`；缺失报告按失败处理，不再把最终自由文本作为可交接结果的回退。

`dteam_dispatch` 的每项 worker 可选带有界 `handoff`：包含带来源的 `facts`、`constraints` 与 `uncertainties`，不包含完整主会话、完整 worker transcript 或 worker 间直接消息。Manager 为报告事实附加实际 worker provenance（来源）；主模型筛选、组合和冲突裁决事实后，显式交给下一轮 worker。`task` 只描述下一轮目标，`handoff` 只传已有证据和边界。

T3 首先完成代码探测或独立小改；T2 只消费已定位的 handoff 做常规实现；T1 不重做低价值探索，只处理路由、综合、冲突裁决、复杂收敛与验收。报告不包含 `suggestedTier`，升级仍由主模型按成本、风险和证据决定。

完整会话共享会破坏 fresh 隔离、带入上下文锚点并增加成本；自由文本回退会把事实提炼重新压回 T1。结构化报告加有界 handoff 保留主模型所有权，同时让跨档交接成为可验证的数据流。
