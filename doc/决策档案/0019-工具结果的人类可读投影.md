# 工具结果的人类可读投影

> **状态：已实施
>
> **补充**：补充 ADR 0013 的公开工具契约、ADR 0018 的等待工具展示规则；不改变内部结构化协议、Signal Log 或模型上下文。

下一主版本中，dteam 的所有用户可见工具结果都必须使用人类可读投影，不能将原始 JSON（JavaScript 对象表示法）、内部 schema（模式）或运行时对象直接展示给用户。

默认视图只显示紧凑摘要：工具动作、关键数量、终态或下一步提示。用户按 `Ctrl+O` 展开时，展示完整但仍为人类可读的文字树、事实条目、错误诊断或 worker 列表；展开不是显示原始 `content` JSON 或 `details` 对象。`dteam_dispatch`、`dteam_respond`、`dteam_recover` 与 `dteam_wait` 均遵守该规则；worker 的 `dteam_report` 是内部结构化工具，不直接成为用户工具行。

完整结构化结果仍保留在模型上下文与内部 `details`，供主模型路由、测试与运行时处理；但 UI renderer（渲染器）必须自行投影为用户文字，不能把 `details` 原样交给宿主默认渲染。Signal Log 与 `/dteam` 也以人类可读方式呈现过程和详情。

这样保留机器可验证的数据流，同时避免用户在正常操作中接触实现结构。代价是每个公开工具都要维护摘要与展开两层投影；收益是所有工具结果在 UI 上有一致、可理解的阅读体验。
