## 目标
实现完整的用户认证模块，包括：
1. 用户注册功能
2. 用户登录功能  
3. Token验证功能
4. Token刷新功能
5. 用户登出功能
6. 集成到dteam工具系统

验收条件：
- [ ] 用户可以成功注册账号
- [ ] 用户可以使用账号密码登录
- [ ] 登录后获得有效的JWT token
- [ ] Token可以被验证和刷新
- [ ] 用户可以安全登出
- [ ] 所有功能通过单元测试

## 范围
包含：
- P0层：认证相关接口定义（User、AuthConfig、LoginRequest、RegisterRequest、AuthResponse、TokenPayload）
- P1层：AuthService服务实现（内存存储、密码哈希、token生成验证）
- P2层：AuthModule模块封装
- 工具层：认证工具接口（auth.register、auth.login、auth.verify、auth.refresh、auth.logout）
- 扩展集成：更新extension/index.ts注册认证工具
- 文档更新：更新README.md添加认证工具说明

不包含：
- 数据库持久化（当前使用内存存储）
- 密码强度验证
- 多因素认证
- OAuth集成
- 生产环境部署配置
