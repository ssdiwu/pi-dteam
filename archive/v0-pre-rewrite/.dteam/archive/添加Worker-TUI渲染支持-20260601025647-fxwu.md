### 2026-06-01 02:56 - 添加TUI消息支持

**问题**: Worker工具执行时没有发送TUI消息，用户看不到Worker状态

**原因**: Worker工具使用了wrap函数，没有发送TUI消息

**解决方案**: 创建wrapWorker函数，在Worker工具执行时发送TUI消息

### 修改内容

1. **创建wrapWorker函数**:
   - 接收workerAction参数，区分不同操作
   - 解析Worker结果，获取workerId和状态
   - 发送TUI消息到pi

2. **更新Worker工具注册**:
   - worker_create → wrapWorker(workerCreate, "create", pi)
   - worker_start → wrapWorker(workerStart, "start", pi)
   - worker_sendSignal → wrapWorker(workerSendSignal, "signal", pi)
   - worker_cancel → wrapWorker(workerCancel, "cancel", pi)
   - worker_status → wrapWorker(workerStatus, "status", pi)

3. **TUI消息格式**:
   - 创建: [DTEAM_PROGRESS] workerId pending Worker created
   - 启动: [DTEAM_PROGRESS] workerId running Executing...
   - 完成: [DTEAM_PROGRESS] workerId done Executing...
   - 取消: [DTEAM_PROGRESS] workerId failed Cancelled
