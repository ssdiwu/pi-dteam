使用 check agent 检查代码质量、验证结果。

任务：$@

## 第一步：判断模式

使用 task_search 搜索与任务描述匹配的 task。

- **找到 task** → 验收模式：读取验收条件，逐条验证
- **没找到 task** → 审查模式：直接审查代码，不依赖 task 工具

## 验收模式（有 task）

1. 使用 task_read 读取「验收条件」和「执行记录」
2. 逐条检查验收条件，标记 PASS/FAIL/BLOCKER
3. 检查代码问题：Bug、安全、性能、可读性
4. 检查文档一致性
5. **必须**使用 task_update 更新「验收条件」section 和写入「阶段记录」

## 审查模式（无 task）

1. 审查用户指定的代码（或当前变更）
2. 检查维度：
   - Bug 和逻辑错误
   - 安全漏洞
   - 性能问题
   - 可读性和命名
   - 错误处理
3. 直接输出审查报告，不调用 task 工具
