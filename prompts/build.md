使用 build agent 执行计划、编写代码、更新文档、编写测试。

任务：$@

## 第一步：查找 task

使用 task_search 搜索与任务描述匹配的 task。

- **找到** → 继续下一步
- **没找到** → 停止，提示用户"请先使用 /explore 或 /design 创建任务并制定方案"

## 第二步：读取执行依据

使用 task_read 读取 task 的：
- 「讨论决策」— 了解要做什么、怎么做
- 「验收条件」— 了解做到什么算完成
- 「探索发现」— 了解约束和风险

## 第三步：执行代码修改

- 按照「讨论决策」中的方案执行
- 只做 plan 中定义的事，不擅自扩大 scope
- 每步修改后做基本验证

## 第四步：更新文档和测试

- 更新相关文档（README、API 文档等）
- 编写单元测试和集成测试
- 确保测试覆盖验收条件

## 第五步：写入执行记录

**必须**使用 task_update 写入 task 的「阶段记录」→「执行记录」section，内容包括：
- 做了什么修改
- 遇到的问题和解决方案
- 未完成的事项
