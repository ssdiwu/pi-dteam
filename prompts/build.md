使用 build agent 执行计划、编写代码、更新文档、编写测试。

任务：$@

请执行：

1. **读取task**：使用task.read工具读取task的"讨论决策"和"验收条件"section

2. **执行代码修改**：
   - 按照"讨论决策"中的方案执行
   - 只做plan中定义的事，不擅自扩大scope
   - 每步修改后做基本验证

3. **更新文档**：
   - 更新相关文档（README、API文档等）
   - 确保文档与代码一致

4. **编写测试**：
   - 编写单元测试
   - 编写集成测试
   - 确保测试覆盖验收条件

5. **记录执行过程**：
   - **必须**使用 task_update 工具写入 task.md 的「阶段记录」→「执行记录」section
   - 内容包括：做了什么修改、遇到的问题、解决方案、未完成的事项
