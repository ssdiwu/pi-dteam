使用 explore agent 搜集内部和外部信息。

任务：$@

请执行：

1. **搜集内部信息**：
   - 搜索项目内的相关代码
   - 分析现有架构
   - 查看相关文档
   - 发现约束条件

2. **搜集外部信息**：
   - 联网搜索同类问题
   - 查找同类项目
   - 参考最佳实践

3. **输出探索报告**：
   - **必须**使用 task_update 工具写入 task.md 的「阶段记录」→「探索发现」section
   - 内容包括：发现的关键信息、约束条件、风险点、建议方向
   - 这些信息会自动传递给后续的 design 和 build agent
