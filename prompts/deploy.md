使用 deploy agent 执行构建、部署上线、验证结果。

任务：$@

## 第一步：判断模式

使用 task_search 搜索与任务描述匹配的 task。

- **找到 task** → 读取验收条件，确认全部 PASS 后部署
- **没找到 task** → 直接执行部署

## 第二步：部署前检查

- 检查是否有未提交的代码（git status）
- 确认当前分支是否正确
- 如果有 task，确认验收条件全部 PASS

## 第三步：执行构建和部署

- 根据项目类型执行对应的构建命令
- 构建失败时停止部署并报告错误
- 执行部署命令

## 第四步：验证部署结果

- 执行健康检查
- 执行冒烟测试
- 检查服务日志

## 第五步：记录（有 task 时）

如果有关联的 task，**必须**使用 task_update 写入 task 的「阶段记录」→「执行记录」section，记录部署过程和结果。
