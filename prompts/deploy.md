使用 deploy agent 执行构建、部署上线、验证结果。

任务：$@

请执行：

1. **读取task**：使用task.read工具读取task的"验收条件"和"执行记录"section

2. **验证验收条件**：
   - 确认所有验收条件都已 PASS
   - 检查是否有未提交的代码（git status）
   - 确认当前分支是否正确

3. **执行构建**：
   - 根据项目类型执行对应的构建命令
   - 构建失败时停止部署并报告错误

4. **执行部署**：
   - 根据项目类型执行对应的部署命令
   - 记录部署过程和结果

5. **验证部署结果**：
   - 执行健康检查
   - 执行冒烟测试
   - 检查服务日志

6. **记录部署信息**：使用task.update工具写入task.md的"部署记录"section
