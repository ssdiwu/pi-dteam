# 对抗回合验证（历史原型）

> **状态：已废弃，仅追溯。** 本目录验证过 ADR 0007 的对抗回合与积分制；该方向已被 ADR 0008 推翻，不能作为当前 dteam 运行时或实现参考。当前实现见 [`../../src/README.md`](../../src/README.md)。

## 职责

保留真实模型实验记录，说明积分制虽能制造方案方差，但默认多轮调用成本过高，因而未吸收进 0.7 的 `dteam_dispatch` 模型分级路由。

## 文件

| 文件 | 说明 |
|---|---|
| `scoring.ts` | 对抗回合积分 reducer（历史实验逻辑） |
| `run.ts` | 历史真实模型实验入口；会 spawn Pi 子进程，**不要作为项目运行命令执行** |
| `NOTES.md` | 实验问题、结论与放弃原因 |
| `real-run.log` / `real-run.stdout` | 历史运行输出 |

## 边界

- 不向 `src/` 吸收本目录代码。
- 不为此原型补测试、模型配置或发布物。
- 若要重新评估对抗机制，先走 ADR 级别决策；不要恢复旧 runtime。
